# ProgramacaoMobile_2026

Repositório da disciplina **Programação Mobile (2026)**, com projetos **exclusivamente para fins educacionais**, destinados à turma de **ADS (Análise e Desenvolvimento de Sistemas)** da **UNIPAR — Campus Toledo**.

## Objetivo

Este repositório reúne exemplos e projetos práticos para apoiar o aprendizado de desenvolvimento **Android com Kotlin**, explorando conceitos fundamentais e boas práticas do ecossistema Android.

## Tecnologias e conteúdos abordados

Os projetos podem incluir (entre outros):

- **Kotlin**
- **Jetpack** (ex.: ViewModel, LiveData/Flow, Navigation, etc.)
- Interfaces com:
  - **XML (Views tradicionais)**
  - **Jetpack Compose** (quando aplicável)
- Persistência de dados com **Room**
- Consumo de APIs com **Retrofit**
- Padrões de arquitetura e organização de código (ex.: MVVM)
- Boas práticas de Android (permissões, lifecycle, componentes, etc.)

## Organização

Os projetos estarão organizados por pastas/módulos conforme as atividades e conteúdos desenvolvidos ao longo das aulas. Cada projeto poderá conter instruções específicas no próprio diretório (quando necessário).

## Aviso

- Todo o conteúdo aqui disponibilizado é voltado ao **aprendizado** e pode conter variações/protótipos.
- Sinta-se à vontade para estudar, modificar e experimentar os exemplos, sempre respeitando as orientações do curso.
